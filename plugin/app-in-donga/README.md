# 앱 인 동아 플러그인

선생님이 Claude와 이야기하면서 수업 게임·수업 도구·학급 운영 도구를 만들 수 있게 돕는 동아출판의 Claude 플러그인이에요. 만든 도구는 HTML 파일 하나로 받아서 앱 인 동아에 올리고, 검수를 거쳐 학생에게 링크·QR로 보낼 수 있어요.

## 무엇을 해 주나요

- **만들기**(`make`): "구구단 퀴즈 만들어 줘"처럼 말하면, 앱 인 동아 규칙에 맞는 도구를 HTML 파일 하나로 만들어 화면에 바로 보여 줘요. 전자칠판·태블릿에서 멀리서도 잘 보이게 큰 글자와 큰 버튼으로 만들고, 정답·철자·계산을 다시 확인해요. "글자를 더 크게 해 줘"처럼 고칠 곳을 말하면 그 부분만 고쳐요.
- **검사**(`check`): 올리기 전에 파일이 규칙에 맞는지 미리 살펴보고, 고칠 곳이 있으면 쉬운 말로 알려 주고 고쳐 줘요.

플러그인은 올리기·검수·공개를 하지 않아요. 파일을 내려받아 앱 인 동아에 올리는 것, 검수 요청을 보내는 것, 학생에게 공개하는 것은 모두 사람이 해요.

## 설치하는 방법

**설치 없이 쓰기**: 앱 인 동아 만들기 가이드의 [시작 글 복사]를 눌러 Claude 새 대화에 붙여 넣으면, 플러그인 없이도 같은 규칙으로 만들 수 있어요.

**Claude Code에서**: 아래 한 줄을 Claude에게 실행해 달라고 하거나 터미널에 붙여 넣은 뒤 `/reload-plugins`를 입력해요(Claude Code 2.1.292 이상).

```
claude plugin install app-in-donga --marketplace cskwork/app-in-donga-plugin --scope user
```

대화창에서는 `/plugin install app-in-donga --marketplace cskwork/app-in-donga-plugin`도 돼요.

**Claude 웹(claude.ai)·데스크톱 앱 채팅에서**: 글로는 설치되지 않아 파일을 올려야 해요.

1. 설정 › Capabilities에서 **Code execution and file creation**을 켜 주세요. 이게 꺼져 있으면 플러그인이 동작하지 않아요.
2. **Customize › Plugins › Add › Upload plugin**을 누르고, 받은 `app-in-donga-plugin.zip` 파일을 올려 주세요.
3. 새 대화에서 "수업에 쓸 게임 만들어 줘"라고 말해 보세요. 직접 고르려면 입력창에 `/`를 누르고 `app-in-donga`를 찾아요.

학교(조직)에서 Claude Team·Enterprise를 쓰면, 관리자가 조직 설정에서 이 플러그인을 **Installed by default**(기본 설치)로 정해 둘 수 있어요. 그러면 선생님은 따로 설치하지 않아도 돼요.

요금제: 플러그인은 Pro, Max, Team, Enterprise 요금제에서 쓸 수 있다고 안내돼 있어요. Free 요금제에서 플러그인을 올릴 수 있는지는 안내 문서에 나와 있지 않아요.

## 다음 버전에서 할 일

- **2단계: 검사·올리기 연결.** 앱 인 동아 서버에 연결하는 원격 커넥터(MCP)를 붙여서, 대화 안에서 바로 검사하고 앱 인 동아에 올리기를 준비할 수 있게 할 거예요. 이번 버전(0.1.0)에는 들어 있지 않아요. 그때도 검수 승인과 공개는 사람이 해요.
