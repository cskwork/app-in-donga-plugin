# 부탁 예시와 잘 만든 결과의 모습

앱 인 동아 샘플 도구 8개는 아래 부탁 하나로 만든 것이다. 결과는 모두 `assets/starter.html` 구조(시작 → 놀이 → 결과 + 다시 하기)를 따르고, 도구마다 색과 분위기만 다르다.

## 만들기 부탁

### 1. 발표자 뽑기 룰렛 (학급 운영, 전 학년)
> 발표자 뽑기 룰렛을 만들어 줘. 학생 이름은 내가 붙여 넣을게. 돌림판이 돌다가 멈추면 이름을 크게 보여 주고, 한 번 뽑힌 학생은 빼 줘. 전자칠판에서 멀리서도 보이게.

- 첫 화면: 이름 붙여 넣는 칸 하나(한 줄에 한 명·쉼표 모두 받음, 예시 이름은 지어낸 이름) + [룰렛 만들기].
- 돌림판은 SVG. 바늘이 가리키는 칸과 뽑힌 이름이 정확히 같다(회전 각도를 계산해 멈춤). 움직임 줄이기면 돌지 않고 바로 보여 준다.
- 뽑힌 이름은 돌림판 위에 아주 크게, [좋아요]를 누르면 빠지고 "발표한 친구" 목록에 들어간다. 모두 뽑으면 결과 화면 + [다시 하기].

### 2. 구구단 스피드 퀴즈 (수업 게임, 초2 수학)
> 초등 2학년 수학 시간에 쓸 구구단 스피드 퀴즈를 만들어 줘. 30초 동안 몇 개 맞히는지 세고, 보기 4개 중에 고르게 해 줘. 단은 선생님이 고를 수 있게.

- 시작 화면에 2~9단 고르기 버튼(누름 상태 표시), 하나도 안 고르면 화면 안 글로 안내.
- 오답 보기는 헷갈리기 쉬운 수(한 줄 앞뒤 곱, 옆 단, ±1, ±10)에서 고르고 정답·서로와 겹치지 않는다. 같은 문제가 연달아 나오지 않는다.
- 틀리면 정답을 초록으로 보여 주고 "7 × 8 = 56"을 글로 알려 준다. 결과 화면에 맞힌 개수·정답률·다시 볼 문제.
- 키보드 1~4로도 고른다.

### 3. 영어 단어 카드 뒤집기 (수업 게임, 초3·4 영어)
> 영어 단어 카드 뒤집기 게임을 만들어 줘. 단어는 apple, banana, cat, dog, egg, fish, grape, hat. 앞면은 그림(이모지)과 영어, 뒷면은 우리말 뜻. 누르면 소리 내어 읽어 줘.

- 뜻: 사과·바나나·고양이·개·달걀·물고기·포도·모자. 철자를 하나씩 확인한다.
- 누를 때마다 `speechSynthesis`(en-US)로 읽는다. 목소리가 없거나 소리가 시작되지 않으면 "단어를 보고 따라 읽어 봐요" 안내와 함께 단어를 글자로 보여 주고 놀이는 계속된다.
- 8장을 모두 보면 [다 봤어요!] → 단어 목록 결과 화면.

### 4. 분수 피자 나누기 (수업 도구, 초3 수학)
> 분수를 배우는 초등 3학년용 피자 나누기 도구를 만들어 줘. 피자를 2~12조각으로 나누고, 조각을 누르면 색칠되면서 '8분의 3'처럼 분수를 크게 보여 줘.

- 바로 쓰는 도구라 시작 화면 없이 첫 화면에 피자. [−]/[+]로 2~12조각.
- "8분의 3"을 크게, 그 아래 3/8 꼴(분자·가로선·분모)도 함께. 다 칠하면 "8분의 8은 1이에요".
- 조각은 키보드(Tab·Enter·Space)로도 누를 수 있고 초점이 보인다.

### 5. 수업 타이머 (학급 운영, 전 학년)
> 수업 타이머를 만들어 줘. 1분·3분·5분·10분 버튼, 남은 시간을 큰 숫자와 줄어드는 원으로 보여 주고, 끝나면 부드러운 소리를 내 줘.

- 버튼을 누르면 바로 시작. 남은 시간은 실제 시각 차이로 계산해(탭이 느려져도 정확) 큰 숫자와 원으로 보여 준다. 잠깐 멈춤·처음으로.
- 끝소리는 Web Audio로 만든 부드러운 종소리(소리 파일 없음). 전자칠판용 어두운 배경, 높은 대비.

### 6. 모둠 나누기 (학급 운영, 전 학년)
> 모둠 나누기 도구를 만들어 줘. 학생 이름을 붙여 넣고 모둠 수를 고르면 무작위로 골고루 나눠 줘. 다시 섞기 버튼도 넣어 줘.

- 섞은 뒤 한 명씩 돌아가며 넣어서 모둠 인원 차이가 1명을 넘지 않는다. "24명 → 모둠마다 4명"처럼 미리 알려 준다.
- 모둠 카드는 색·동물 이모지로 구분, 이름은 멀리서도 보이게 크게. 전자칠판 한 화면에 모두 들어간다.

### 7. 듣고 철자 맞히기 (수업 게임, 초5·6 영어)
> 영어 단어를 듣고 철자를 맞히는 게임을 만들어 줘. 단어를 소리로 들려주고, 알파벳 버튼을 눌러 철자를 완성하게 해 줘. 틀리면 힌트로 첫 글자를 보여 줘.

- 단어는 학년 수준(friend, school, library 등)과 뜻·이모지. 칸 수 = 글자 수.
- 알파벳 버튼(48px 이상)과 실제 키보드 모두 된다. 한 번 틀리면 첫 글자를 채워 주고 다시 들려준다. 두 번째도 틀리면 정답을 보여 주고 다음으로.
- 목소리가 없으면 [단어 보기]로 3초 동안 단어를 보여 준다.

### 8. 시계 읽기 퀴즈 (수업 게임, 초1 수학)
> 초등 1학년 시계 보기 퀴즈를 만들어 줘. 바늘 시계를 보여 주고 '몇 시 몇 분'을 보기 3개 중에 고르게 해 줘. 처음엔 정각과 30분만 나오게.

- 바늘 각도: 긴바늘 = 분 × 6도, 짧은바늘 = (시 % 12) × 30도 + 분 × 0.5도. 그래서 3시 30분이면 짧은바늘이 3과 4 가운데에 있다.
- 처음 단계는 정각·30분만. 오답은 1학년이 자주 헷갈리는 것(짧은바늘을 다음 숫자로 읽기 등). 끝나면 [5분 단위 도전하기]를 따로 둔다.
- 틀리면 "짧은바늘이 3과 4 사이, 긴바늘이 6에 있으면 3시 30분이에요."처럼 이유를 알려 준다(조사 이에요/예요, 과/와를 맞춘다).

## 고치기 부탁

### A. 글자 크기
> 글자를 더 크게 해 줘. 교실 맨 뒤에서도 보이게.

- 글자 크기 변수(`--text`, `--big`, 문제·보기 글자)만 키운다. 문제·색·동작은 그대로.
- 키운 뒤에도 1920×1080·태블릿에서 넘치거나 잘리지 않게 `clamp()` 최댓값과 줄바꿈을 함께 맞춘다.
- "본문과 문제 글자를 약 1.5배로 키웠어요"처럼 바꾼 것만 한 줄로 알려 준다.

### B. 화면 캡처와 함께
> (화면 캡처를 붙여 넣고) 이 버튼이 안 눌려요. 고쳐 줘.

- 캡처에서 어떤 버튼인지 찾고 원인을 본다: 다른 요소에 가려짐(돌아가는 그림·겹친 상자), 너무 작음, 화면 밖, 이벤트 연결 빠짐, 비활성 상태가 안 풀림.
- 원인만 고친다. "돌림판 그림이 버튼 위를 덮고 있어서 눌리지 않았어요. 그림이 버튼을 덮지 않게 고쳤어요."처럼 쉬운 말로 알려 준다.

### C. 앱 인 동아 검사 결과 붙여 넣기
> 앱 인 동아에 올리려고 검사했더니 아래 문제가 나왔어요. 고쳐서 HTML 파일 하나로 다시 만들어 주세요. … 1. 인터넷으로 정보를 주고받는 코드가 있어요 (52번째 줄) …

- 목록에 있는 항목만 고친다. 예: 점수를 인터넷으로 보내는 `fetch`는 빼고 점수는 화면에만 보여 준다. `localStorage` 최고 점수는 화면을 닫으면 사라지는 변수로 바꾼다. `alert`·`confirm`은 화면 안 글과 버튼으로 바꾼다. 인터넷 글꼴은 시스템 한글 글꼴로 바꾼다.
- 고친 파일을 다시 검사해서 걸리는 것이 없을 때 넘긴다.
