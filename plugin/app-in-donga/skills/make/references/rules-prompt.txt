[앱 인 동아 규칙] 아래 규칙을 지켜 학생용 수업 도구를 만들어 주세요.
1. HTML 파일 하나로 만들어 주세요. 스크립트·스타일·그림을 모두 파일 안에 넣고, CDN·외부 글꼴·외부 그림을 쓰지 마세요.
2. 인터넷에 연결하지 마세요(fetch·XMLHttpRequest·WebSocket 금지). eval·iframe·window.open도 쓰지 마세요.
3. 학생 개인정보(전화번호·이메일·주소·생년월일)를 묻지 마세요. 학생 이름이 필요하면 선생님이 화면에 붙여 넣게 해 주세요.
4. 기록 저장(localStorage)과 알림 창(alert)은 쓰지 마세요. 안내는 화면 안에 글로 보여 주세요.
5. 전자칠판·태블릿에서 멀리서도 보이게: 본문 글자 18px 이상, 버튼은 48px 이상, 대비는 높게. <meta name="viewport" content="width=device-width, initial-scale=1">과 <title>을 넣어 주세요.
6. 첫 화면에 무엇을 하는지 한 줄과 시작 버튼 하나만 두세요. 정답·철자·수식은 정확하게, 학년 수준에 맞는 쉬운 말로 써 주세요.
7. 광고·결제·외부 링크·실존 캐릭터나 브랜드는 넣지 마세요. 움직임 줄이기 설정(prefers-reduced-motion)을 따라 주세요.
