# 선생님 도구 규칙

앱 인 동아에 올리는 게임·수업 도구가 지켜야 할 규칙의 정본입니다. 자동 검사(`src/apps/checks.js`), AI에게 붙여 넣는 짧은 규칙(`docs/apps/rules-prompt.txt`), 동아 Claude 플러그인 스킬(`plugin/app-in-donga/`), 만들기 가이드, 검수하는 사람이 모두 이 문서를 따릅니다. 규칙을 바꾸면 함께 바꿉니다. 플러그인 안의 사본은 `npm run apps:plugin`이 여기서 복사합니다.

Content Forge로 만든 콘텐츠(학생에게 보낼 파일 HTML)도 같은 검사를 거칩니다. 예시 콘텐츠(수학 18쪽)는 3.4MB이고 `storage` 경고(sessionStorage)만 나옵니다(2026-10-31 확인).

## 도구의 모양

- **HTML 파일 하나.** 스크립트·스타일·그림을 모두 이 파일 안에 넣습니다. 최대 5MB.
- **인터넷 없이 동작.** 학생 화면은 인터넷에 연결하지 않습니다(외부 글꼴·그림·CDN·API 모두 안 됨).
- **어디서나 크게.** 전자칠판(16:9 가로), 학생 태블릿(가로·세로), PC 크롬에서 같은 파일이 동작합니다.

## 자동 검사(올리기 화면·플러그인 점검)

`error`가 하나라도 있으면 검수 요청을 보낼 수 없습니다. `warn`은 올릴 수 있지만 검수하는 사람이 함께 봅니다.

| id | 단계 | 무엇 | 왜 |
|---|---|---|---|
| `not-html` | error | HTML 문서가 아님 | 학생 화면은 HTML만 엽니다 |
| `too-big` | error | 5MB 초과 | 학생 태블릿에서 첫 화면이 늦어집니다 |
| `outside-code` | error | `<script src>`·스타일시트 `<link>`로 다른 파일·인터넷 코드를 불러옴 | 학생 화면은 파일 하나만 받고 인터넷을 막아 동작하지 않습니다. 검수한 뒤 코드가 바뀔 수도 있습니다 |
| `network` | error | `fetch`·`XMLHttpRequest`·`WebSocket`·`sendBeacon`·`EventSource`·jQuery ajax | 학생 정보가 밖으로 나갈 수 있습니다 |
| `eval` | error | `eval`·`new Function`·글자로 된 `setTimeout`·`setInterval` | 검수하지 않은 코드가 실행될 수 있습니다(토스 앱인토스도 금지) |
| `iframe` | error | `<iframe>` | 검수하지 않은 다른 화면이 들어옵니다 |
| `personal-info` | error | 전화번호·이메일·주소·생년월일·주민번호를 묻는 칸 | 학생 개인정보를 받지 않습니다. 학생 이름은 선생님이 화면에 붙여 넣는 것만 허용합니다 |
| `device-access` | error | 카메라·마이크·화면 공유·위치 | 학생 기기의 민감한 기능을 쓰지 않습니다 |
| `outside-media` | warn | 인터넷 그림·글꼴·소리(`img src=https://…`, 구글 글꼴 등) | 학생 화면에서 빈칸으로 보입니다 |
| `leave-site` | warn | 외부 링크·`window.open`·`location` 이동 | 학생 화면에서는 다른 사이트로 나갈 수 없습니다 |
| `storage` | warn | `localStorage`·`sessionStorage`·`indexedDB`·쿠키 | 학생 화면은 기록을 저장하지 않습니다(화면을 닫을 때까지만 기억) |
| `popup-dialog` | warn | `alert`·`confirm`·`prompt` | 알림 창이 뜨지 않을 수 있습니다(`alert`만 화면 안 알림으로 바꿔 보여 줌) |
| `no-viewport` | warn | `<meta name="viewport">` 없음 | 태블릿에서 글자가 아주 작게 보입니다 |
| `no-title` | warn | `<title>` 없음 | 올릴 때 이름으로 씁니다 |

주석 속 글자는 검사하지 않습니다. 단 코드 뒤에 붙은 줄 끝 주석(`x(); // fetch(...)`)은 주소와 구분하기 어려워 검사합니다.

## 실행 검사(올리기 화면)

글자 검사는 `window['fe'+'tch']`처럼 숨긴 코드를 못 잡습니다. 그래서 올리기 화면은 글자 검사 뒤에 파일을 학생 화면과 같은 조건(sandbox + CSP)으로 보이지 않는 곳에서 몇 초 실행해 보고(`src/apps/runcheck.ts`), 글자 검사가 놓친 것만 더합니다. 실행 검사가 끝나기 전에는 검수 요청을 보낼 수 없습니다. 플러그인 점검 스크립트(Node)는 실행 검사를 하지 않습니다.

| id | 단계 | 무엇 |
|---|---|---|
| `runtime-network` | error | 실행하니 CSP가 인터넷 연결·외부 스크립트·외부 페이지를 막음(글자 검사의 `network`·`outside-code`·`iframe`이 없을 때만) |
| `runtime-eval` | error | 실행하니 문자열 코드 실행을 막음(글자 검사의 `eval`이 없을 때만) |
| `runtime-media` | warn | 실행하니 외부 그림·글꼴·소리를 막음(글자 검사의 `outside-media`가 없을 때만) |
| `runtime-error` | warn | 실행 중 오류 |
| `runtime-slow` | warn | 6초 안에 첫 화면이 다 뜨지 않음 |
| `runtime-blank` | warn | 첫 화면에 글자도 그림·버튼·입력도 없음 |

한계: 첫 화면 뒤 약 1초까지만 봅니다. 늦게 또는 눌러야 일어나는 연결은 못 보지만, 학생 화면의 CSP가 그때도 막습니다. **막는 것은 CSP와 sandbox이고, 두 검사는 막힐 파일을 미리 알려 주는 것입니다.**

## 사람이 보는 것(검수)

자동 검사로 잡을 수 없어 검수하는 사람이 학생 화면을 직접 열어 봅니다.

1. **멀리서 읽힌다.** 본문 글자 18px 이상(전자칠판에 띄울 화면은 24px 이상), 높은 대비(WCAG AA 4.5:1).
2. **누르기 쉽다.** 버튼·카드 등 누르는 곳은 48×48px 이상. 드래그는 누르기로도 할 수 있어야 합니다.
3. **처음 봐도 안다.** 첫 화면에 무엇을 하는지 한 줄, 시작 버튼 하나.
4. **내용이 맞다.** 정답·해설·철자·수식이 맞고 학년 수준에 맞습니다. 정답 확인은 선생님 책임이고, 검수에서 다시 봅니다.
5. **학생에게 안전하다.** 광고·결제·학생끼리 대화·외부 링크 없음. 겁주거나 놀리는 말 없음.
6. **권리 문제가 없다.** 실존 캐릭터·브랜드·교과서 지문·음원을 허락 없이 쓰지 않습니다. 교과서 지문을 쓰려면 사용 범위를 먼저 확인합니다.
7. **AI가 만든 그림·글은 표시한다.** AI가 만든 결과를 학생에게 그대로 보여 주는 도구는 "AI가 만들었어요"를 화면에 적습니다.
8. **움직임 줄이기를 따른다.** `prefers-reduced-motion`에서는 큰 움직임을 끕니다.

## 학생 화면

이 문서는 공개 플러그인 저장소에도 그대로 들어갑니다. 서비스 계획·검토 중인 사항은 여기 쓰지 않고 AGENTS.md '앱 인 동아 규칙'에 둡니다.

- 학생 화면은 `sandbox="allow-scripts"` iframe + 문서 맨 앞 CSP(`src/apps/runtime.js`)로 엽니다. CSP meta는 doctype 바로 뒤, 어떤 태그보다 먼저 넣습니다(`<head>` 뒤에 넣으면 그 앞의 스크립트가 CSP 없이 실행됨, 2026-10-31 확인). 인터넷 연결·외부 파일·eval이 막히고, 플랫폼 화면·쿠키에 손대지 못합니다.
- 학생은 로그인 없이 링크·QR로 열고, 학생 개인정보를 받지 않습니다.
- 공개는 사람만 합니다. 선생님의 AI(플러그인)는 검사·미리보기·검수 요청 준비까지만 하고, 검수 승인과 공개는 사람이 누릅니다.
