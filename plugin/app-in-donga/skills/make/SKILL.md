# 앱 인 동아 도구 만들기

선생님(개발자가 아님)이 말한 수업 도구를 **HTML 파일 하나**로 만든다. 이 파일은 선생님이 내려받아 앱 인 동아에 올리고, 사람이 검수한 뒤 학생 태블릿·전자칠판에서 인터넷 없이 열린다.

## 1. 물어볼지 정하기

- 학년·과목, 또는 어디서 쓰는지(전자칠판에 띄움 / 학생 태블릿에서 각자)가 **분명하지 않을 때만** 짧은 질문을 **최대 2개** 한 번에 묻는다. 예: "몇 학년 수업에 쓰실 건가요?", "전자칠판에 띄우실 건가요, 학생이 태블릿으로 하나요?"
- 그 밖에는 묻지 말고 바로 만든다. 모르는 세부(문제 수, 색 등)는 학년에 맞게 정하고, 끝에 한 줄로 알려 준다.
- 사진·화면 캡처를 붙이면 그 내용을 따른다.

## 2. 만들기

1. `assets/starter.html`을 읽고 그 구조에서 시작한다: CSS 변수, 시작 화면(무엇을 하는지 한 줄 + 시작 버튼 하나) → 놀이 화면 → 결과 화면 + [다시 하기], 큰 글자, 초점 테두리, 움직임 줄이기, 시스템 한글 글꼴. 타이머·분수 피자처럼 바로 쓰는 도구는 시작 화면 없이 첫 화면에서 바로 쓰게 해도 된다.
2. `references/rules.md`를 따른다. 꼭 지킬 것:
   - 파일 하나. `<script src>`·외부 CSS·CDN·외부 글꼴·외부 그림 없음. 그림은 이모지·인라인 SVG·CSS로.
   - `fetch`·`XMLHttpRequest`·`WebSocket`·`sendBeacon` 없음. `eval`·`new Function`·`iframe`·`window.open`·`location` 이동 없음.
   - `localStorage`·`sessionStorage`·`indexedDB`·쿠키 없음(화면을 닫으면 사라져도 되게).
   - `alert`·`confirm`·`prompt` 없음. 안내는 화면 안 글로(`role="status"`).
   - 학생 개인정보(전화·이메일·주소·생년월일) 입력 칸 없음. 학생 이름이 필요하면 선생님이 붙여 넣는 칸 하나.
   - 카메라·마이크·위치 없음.
   - `<meta name="viewport" content="width=device-width, initial-scale=1">`, `<title>`(도구 이름), `<html lang="ko">`.
   - 본문 18px 이상, 놀이의 핵심 글자 24px 이상, 누르는 곳 48×48px 이상, 대비 4.5:1 이상, 키보드로도 조작, `prefers-reduced-motion`을 따른다.
   - 1920×1080(전자칠판), 1024×768·768×1024(태블릿), 390×844(휴대폰)에서 넘치거나 잘리지 않게 `clamp()`·그리드로 맞춘다.
   - 소리 읽기는 `speechSynthesis`(영어는 `en-US`). 목소리가 없으면 단어를 글자로 보여 주고 놀이는 계속되게 한다. 효과음은 Web Audio로 만든다(소리 파일 없음).
   - 광고·결제·외부 링크·실존 캐릭터·브랜드·교과서 지문 없음. 겁주거나 놀리는 말 없음.
3. 화면 글은 모두 친근한 해요체로, 짧게 쓴다(예: "정답이에요!", "다시 해 봐요").

## 3. 내용이 맞는지 확인하기

넘기기 전에 반드시 확인한다. 자기 평가로 대신하지 않는다.

- 수학: 정답과 오답 보기를 코드로 다시 계산한다(코드 실행이 되면 실제로 돌려 본다). 오답 보기가 정답과 겹치지 않고, 보기끼리 겹치지 않는지 본다. 분수는 "8분의 3"처럼 말로, 3/8 꼴로도 보여 준다. 시계는 짧은바늘 각도 = (시 % 12) × 30 + 분 × 0.5, 긴바늘 = 분 × 6.
- 영어: 철자·뜻을 하나씩 확인한다. 한국어: 맞춤법과 조사(이에요/예요, 과/와)를 확인한다.
- 학년 수준에 맞는 낱말·문제인지 본다.
- 코드 실행이 되면 `check` 스킬의 검사 스크립트로 파일을 검사한다. 안 되면 `references/rules.md` 표의 항목을 파일에서 하나씩 찾아본다. 걸린 것은 고친 뒤 넘긴다.

## 4. 넘기기

- 결과는 **HTML 파일 하나를 아티팩트로** 보여 준다(선생님이 바로 눌러 보고 내려받을 수 있게). 파일 만들기가 되면 `<도구 이름>.html` 파일도 함께 만든다. 코드 조각을 나눠 주지 않는다.
- 마지막에 아래 안내를 그대로(도구에 맞게 이름만 바꿔) 붙인다.

```
다 만들었어요! 오른쪽 화면에서 먼저 눌러 보세요.
학생에게 보내려면 이렇게 해요.
1. 화면 위의 내려받기 버튼으로 파일을 받아요.
2. 앱 인 동아에서 [+ 올리기]를 누르고, 받은 파일을 끌어다 놓아요.
3. 자동 검사가 끝나면 [검수 요청]을 눌러요. 검수가 끝나면 학생에게 보낼 수 있어요.
고치고 싶은 곳이 있으면 "글자를 더 크게 해 줘"처럼 편하게 말해 주세요.
```

## 5. 고치기

- 선생님이 말한 것**만** 고친다. 내용·문제·디자인·동작 중 요청하지 않은 것은 그대로 둔다.
- 고친 뒤에도 파일 하나 전체를 다시 아티팩트로 보여 주고, 무엇을 바꿨는지 한두 줄로 알려 준다.
- 화면 캡처와 함께 "안 눌려요", "안 보여요"라고 하면, 캡처에서 그 부분을 찾아 원인(가려짐·너무 작음·화면 밖)을 고친다.
- 앱 인 동아 검사 결과(고칠 곳 목록)를 붙여 넣으면 그 항목만 고친다.

## 하지 않는 것

- 올렸다, 검수를 통과했다, 공개했다, 학생에게 보냈다고 말하지 않는다. 이 플러그인은 올리지도, 검수하지도, 공개하지도 못한다. 올리기·검수 요청은 선생님이, 검수 승인·공개는 사람이 한다.
- 선생님에게 하는 말과 도구 화면에 개발 용어(배포·번들·MCP·sandbox·CSP·빌드·API 등)를 쓰지 않는다. 만들기·올리기·검사·검수·학생에게 보내기라고 쓴다.

## 참고 파일

- `assets/starter.html`: 시작 템플릿
- `references/rules.md`: 도구 규칙 정본(자동 검사 항목과 사람이 보는 항목)
- `references/rules-prompt.txt`: 다른 AI에 붙여 넣는 짧은 규칙
- `references/examples.md`: 좋은 부탁 예시와 잘 만든 결과의 모습
